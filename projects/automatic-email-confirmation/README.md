# Automatic Email Confirmation

## Overview

This n8n workflow automatically sends a confirmation email when someone submits a form with their name and email address.

## How It Works

1. The user submits the form.
2. n8n receives the submitted information.
3. Gmail automatically sends a confirmation email.

## Tools Used

* n8n
* Gmail

## What I Learned

* Creating form-triggered workflows
* Connecting Gmail to n8n
* Sending automated emails
* Testing and activating workflows
