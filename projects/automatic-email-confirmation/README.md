# Project 2: Automatic Email Confirmation

## Overview

This project uses n8n to automatically send a confirmation email when a user submits a form with their name and email address.

## How It Works

1. The user submits the form.
2. n8n receives the submitted information.
3. Gmail sends a confirmation email automatically.

## Tools Used

* **n8n:** Workflow automation
* **Gmail:** Sending confirmation emails

## What I Learned

* Creating form-triggered workflows
* Connecting Gmail to n8n
* Mapping form fields into an automated workflow
* Testing and activating workflows
