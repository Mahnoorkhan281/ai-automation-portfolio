Automatic Email Confirmation

Overview

This n8n workflow sends an automatic confirmation email when someone submits a form with their name and email address.

Workflow

1. A user submits the form.
2. n8n receives the submission.
3. Gmail automatically sends a confirmation email.

Tools Used

- n8n
- Gmail

What I Learned

- Building form-triggered workflows
- Connecting Gmail to n8n
- Sending automated emails
- Testing and activating workflows
